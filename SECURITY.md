# Security Policy

## Current status

Heirloom is pre-production. No contract in this repository is approved for meaningful-value
mainnet use until the exact release has completed an independent audit and remediation.

## Reporting

Do not publish suspected vulnerabilities while the repository is private. Report them to the
repository owner through a private GitHub security advisory.

Include:

- Affected commit and contract.
- Preconditions and attacker capabilities.
- Minimal reproduction or failing test.
- Impact on a v3.1 invariant.
- Suggested mitigation if known.

## Mainnet gate

The release owner must record the audit report, remediation commit, deployed bytecode hash and
BaseScan verification before removing the pre-production warning.
